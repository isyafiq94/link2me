# link2me - Perodua Viva 850 scanner

Android app skeleton for Bluetooth Classic SPP ELM327 adapters.

Features: Bluetooth paired-device picker, adapter initialization, OBD-II live data and DTC readout.

Note: generic ELM327 OBD-II is not proof of support for a specific Perodua K-line ECU. Vehicle/adapter testing is required for KWP/ISO-14230 addressing and initialization.
